# bovico.gr

Σελίδα εταιρικών στοιχείων δημοσιότητας της ΜΠΟΒΙΚΟ Ε.Π.Ε. (BOVICO LTD).

- `index.html` – η σελίδα
- `CNAME` – το domain (bovico.gr) για το GitHub Pages
- `oikonomikes-katastaseis-ΕΤΟΣ.pdf` – οι οικονομικές καταστάσεις κάθε χρήσης

Κάθε χρόνο: ανέβασε το νέο PDF και πρόσθεσε μια γραμμή στην ενότητα «Οικονομικές καταστάσεις» του index.html.
